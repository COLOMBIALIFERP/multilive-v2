Administración del servicio

Las cuentas se agregan, consultan y eliminan directamente desde Discord mediante /stream. Las claves privadas se configuran una sola vez en Netlify. Esta página no muestra contraseñas ni tokens.

Comandos: /stream agregar, /stream eliminar, /stream lista, /stream directos y /stream revisar. Consulta el README para instalarlo.

Instalar comandos /stream en tu Discord (una sola vez)

Tras configurar DISCORD_APPLICATION_ID, DISCORD_PUBLIC_KEY, DISCORD_GUILD_ID y DISCORD_BOT_TOKEN en Netlify, pega aquí tu clave TEST_SECRET para registrar el comando en tu servidor. Primero debes guardar la URL de interacciones en el Portal de Discord.

Solo se envía tu clave al endpoint protegido de este mismo sitio. No introduzcas aquí el token del bot ni la URL del webhook.
